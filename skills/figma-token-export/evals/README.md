## ต่างจาก `selftest.mjs` ยังไง

`selftest.mjs` ทดสอบว่า **สคริปต์** ทำงานถูก — assertion บน colour
normalization, การ resolve composite, identifier collision, rollback ฯลฯ
รันได้ในเครื่องเปล่า ไม่ต้องมี Figma

eval ทดสอบว่า **agent เดินกระบวนการถูก** — ถามเรื่อง mode ก่อนดึงไหม
ไป list หน้าด้วย REST ตอน MCP บอกไม่ครบไหม อ่าน `other` ไหม
ผ่าน selftest ไม่ได้แปลว่าผ่าน eval คนละเรื่องกัน

## วิธีรัน

รันใน **เซสชันใหม่ที่ไม่เคยเห็นสกิลนี้** เพราะเซสชันที่ช่วยเขียนสกิลรู้เจตนาอยู่แล้ว
จึงมองไม่เห็นช่องว่าง

```
รอบ baseline   → เซสชันใหม่ ไม่โหลดสกิล  → ให้ query
รอบ with-skill → เซสชันใหม่ โหลดสกิล     → ให้ query เดิม
```

อย่างละ 3 ครั้ง เป้าหมายคือความคงเส้นคงวาของ*กระบวนการ* ครั้งเดียววัดไม่ได้

`eval-01` ต้องมี Figma MCP ต่ออยู่และมีสิทธิ์เข้าไฟล์ ส่วน `eval-02` กับ `eval-03`
จัดฉากได้ในเครื่องด้วยการแก้ `tokens.config.json` และ `dumps/` ตามที่ระบุใน `files`

## วิธีให้คะแนน

แต่ละข้อใน `expected_behavior` ให้ผ่านหรือไม่ผ่าน ไม่มีคะแนนกลาง

ข้อที่ตกบอกว่าต้องไปแก้ที่ไหน: ตกเรื่องการยิง → แก้ `description` · ตกเรื่องขั้นตอน
→ ลับ **Done when** ของขั้นนั้น · ไม่เคยเปิดไฟล์แนบ → แก้ถ้อยคำ pointer

## ครั้งแรก — บอก Claude ว่าจะเอาอะไร

เปิด Claude Code ในโปรเจกต์ แล้วพิมพ์ประมาณนี้ **พร้อมแปะลิงก์ Figma**:

> เอา design token จากไฟล์นี้มาใส่โปรเจกต์ให้หน่อย เป็น CSS + TypeScript
> https://www.figma.com/design/SjE7hLqGcKYLy4XMgXGhlM/Design-system?node-id=59-862

บอกด้วยว่าปลายทางเป็นอะไร: **CSS + TypeScript** (เว็บ) · **Dart** (Flutter) ·
**JSON มาตรฐาน** (ส่งต่อ tool อื่น หรือ import กลับเข้า Figma)

### ลิงก์ที่ดีคือลิงก์แบบเจาะเฟรม

ลิงก์หน้าเปล่า ๆ มักไม่พอ เพราะ Figma ยอมให้อ่าน variable เฉพาะที่ผูกอยู่ใน
โหนดที่ระบุ วิธีได้ลิงก์ที่ใช้ได้แน่ ๆ:

> ใน Figma → คลิกขวาที่**เฟรมเอกสาร** (เช่น `Spacing-Overview`) →
> **Copy link to selection**

ทำแบบนี้กับทุกหน้าที่มี token: สี · typography · spacing · radius · shadow
ส่งมาให้ครบทีเดียวจะเร็วที่สุด

ถ้าคุณไม่รู้ว่าไฟล์มีหน้าอะไรบ้าง บอก Claude ว่า "ช่วยลิสต์หน้าในไฟล์นี้ให้หน่อย"
มันหาเองได้ถ้ามี Figma token อยู่ในโปรเจกต์

## Claude จะถามกลับ 1 เรื่อง — เรื่อง mode

**"จะเอา mode ไหนบ้าง — light อย่างเดียว หรือ dark ด้วย?"**

ต้องตอบให้ชัดตั้งแต่แรก เพราะ Figma ส่งค่าให้ได้ทีละ mode เท่านั้น
ถ้าอยากได้ dark ด้วยต้องมีคนสลับ mode ใน Figma ระหว่างที่ดึง — **เพิ่มทีหลัง
โดยไม่กลับไปที่ Figma ไม่ได้** ตอบผิดคือเสียเวลาหนึ่งรอบเต็ม

## เสร็จแล้วได้อะไร

Claude จะสรุปให้ประมาณนี้:

```
615 สี, 72 ขนาด, 51 text style, 4 เงา
ไฟล์: src/tokens/tokens.css, src/tokens/tokens.ts
```

**เอาไปใช้ยังไง (ฝั่งเว็บ):**

```ts
import { colorVar, spacing, boxShadowVar } from './tokens/tokens';

<div style={{ background: colorVar.colorSurfacePrimaryDefault, padding: spacing.md }} />
```

```html
<!-- text style มีคลาสสำเร็จรูปให้ -->
<h1 class="typography-heading-heading-1-bold">หัวข้อ</h1>
```

**กฎเดียวที่ต้องจำ:** ใช้ตัวที่ลงท้าย `Var` (`colorVar`, `boxShadowVar`)
เพราะเปลี่ยนธีมตอนรันได้ ส่วนตัวที่ไม่มี `Var` เป็นค่าตายตัว ใช้เฉพาะตอนที่
CSS variable ไปไม่ถึงจริง ๆ (canvas, inline SVG)

ฝั่ง Flutter จะได้เป็นคลาส `AppColors`, `AppSpacing`, `AppTypography`, `AppShadows`

## ดีไซน์แก้ Figma แล้วทำยังไง

พิมพ์:

> sync token จาก Figma ใหม่ที

Claude จะดึงใหม่แล้ว**บอกว่าอะไรเปลี่ยนบ้าง**:

```
~ สี text/primary/default: #030712 → #111827
+ ขนาด spacing/12 = 12
- สี color/legacy/accent (หายไป)
```

**เอาสรุปนี้แปะลง PR** — มันคือคำตอบของ "ต้องไปแก้อะไรบ้าง" ที่คนรีวิวอยากรู้

ถ้ามีอันที่ถูกลบ (`-`) ให้เช็คก่อนว่ามีโค้ดที่ยังใช้อยู่หรือเปล่า

## 2 ข้อห้าม

**1. ห้ามแก้ไฟล์ที่ generate มาด้วยมือ** (`tokens.css`, `tokens.ts`, `*.g.dart`)
รอบหน้าที่ sync จะโดนเขียนทับหมด ถ้าค่าไหนผิด บอก Claude ว่าผิดตรงไหน
ให้มันไปแก้ที่ต้นทาง

**2. ห้ามพิมพ์ค่าสี/ขนาดเองในโค้ดขนานไปกับ token** พอมีสองแหล่ง มันจะไม่ตรงกัน
แล้วไปโผล่เป็นบั๊กในหน้าที่ไม่มีใครดูอยู่

## ถ้า Claude บอกว่าติดอะไร แปลว่า...

| มันบอกว่า | แปลว่า | คุณต้องทำ |
|---|---|---|
| ขอลิงก์แบบเจาะเฟรม | ลิงก์ที่ให้ไปเป็นหน้าเปล่า ไม่มี token ผูกอยู่ | คลิกขวาที่เฟรม → Copy link to selection |
| ชื่อ token ชนกัน | มี 2 ชื่อใน Figma ที่แปลงเป็นชื่อในโค้ดแล้วซ้ำกัน | ให้ดีไซน์เปลี่ยนชื่อใน Figma หนึ่งอัน แก้ที่โค้ดไม่ได้ |
| มี N ตัวที่อ่านไม่ออก อยู่ใน `other` | ส่วนใหญ่เป็นชิ้นส่วนของ text style ที่รวมเข้าไปแล้ว **ปกติ** | ดูรายชื่อผ่าน ๆ ถ้าเห็นตัวที่คุณคาดว่าต้องได้ ให้บอก Claude |
| อยากได้ dark mode ต้องดึงใหม่ | mode เพิ่มทีหลังไม่ได้ | ให้คนเปิด Figma สลับเป็น dark แล้วดึงอีกรอบ |
| ได้ token น้อยกว่าที่คิด | ยังส่งลิงก์ไม่ครบทุกหน้า | ส่งลิงก์หน้าที่เหลือเพิ่ม |
